# Capella

An unofficial tutorial site for CharaChorder 3D input devices (CharaChorder
One, CharaChorder Two, CCU, and Master Forge).

## Links

- [Website](https://andy23512.github.io/capella/)

## About

CharaChorder devices swap a traditional keyboard's flat grid of keys for
switches that move in five directions, letting one finger produce many
different characters — and letting whole words come out from a single chord
of switches pressed together. Capella walks through how the hardware works
and how to actually use it, one short chapter at a time.

## Units

- Unit 1: Introduction
- Unit 2: Standard Keys
- Unit 3: CharaChorder Special Keys
- Unit 4: Basic Chording
- Unit 5: Advanced Chording

Each unit's chapters pair an explanation with an interactive device-layout
diagram, and most pair with a hands-on exercise that listens for real
keystrokes from a connected device.

## Development

```bash
yarn
yarn start   # serve locally
yarn build   # production build
```

Deployment to GitHub Pages runs automatically on every push to `main` (see
`.github/workflows/main.yml`).
