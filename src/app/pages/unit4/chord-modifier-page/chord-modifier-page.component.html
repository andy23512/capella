Unit 4: Basic Chording

Chapter 3: Chord Modifier

A chord modifier is an input added alongside a chord that changes its output rather than replacing it — the chord still fires, just altered. Common changes include:

  • Capitalization — capitalizes the output ("run" → "Run")
  • Present Tense — ("run" → "running", "work" → "working")
  • Pluralizer — ("box" → "boxes", "dog" → "dogs")
  • Past Tense — ("run" → "ran")
  • Comparative — ("big" → "bigger", "small" → "smaller")

Each of these five has a fixed default switch — it's not something you choose yourself the way a chord's own switches are. Which switch differs by device model, so there's no single diagram to show here. What is fixed across devices is the timing option available to trigger one: a modifier can be added at the same time as the chord, or arpeggiately — a quick tap right after — which is the timing mechanic covered next.
