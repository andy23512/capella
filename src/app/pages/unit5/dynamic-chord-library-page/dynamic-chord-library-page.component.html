Unit 5: Advanced Chording

Chapter 2: Dynamic Chord Library

Every chord you train normally lives in one shared library — so the same set of switches can only ever mean one thing. A dynamic chord library lets you have more than one library active at a time, each with its own chords, so the exact same input can produce different output depending on which library is active. That's useful for keeping, say, an email-signature set of chords separate from a coding set, even if they'd otherwise clash.

A dynamic library is activated by a special action included in a chord's own output — pressing that chord both produces its output and switches your device into that library going forward. Any new chords you train while it's active are nested one level under it, rather than mixed into your base library. A separate action switches you back to your base library, deactivating whichever dynamic library was active.

Unlike Impulse Chord's switch in the last unit, neither of these two actions is bound to a switch on the default layout — like a chord itself, where you put them (if at all) is entirely up to you, so there's no diagram to show here.
